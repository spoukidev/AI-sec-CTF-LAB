# Lab safety and responsible use

This repository is an intentionally vulnerable educational environment. Run it only on a system you own or are authorized to use.

The lab does not scan or call external systems, collect credentials, execute model-generated commands, or contain real secrets. Challenge actions are deterministic simulations against synthetic records. Docker ports are bound to `127.0.0.1` by default.

Do not adapt exercises to third-party targets. Report defects in the containment boundary privately to the repository owner.
